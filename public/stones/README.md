# Stone swatch images

Stones that exist in both bead sizes use a `-8mm` suffix to avoid clashing
(e.g. `jade.jpg` is the 6mm jade, `jade-8mm.jpg` is the 8mm jade).

## 6mm

Save each bead photo here with the **exact filename** below. The customiser
([src/data/stones.ts](../../src/data/stones.ts)) references these paths, so the
name must match exactly. Square crops (e.g. 600×600) look best.

| Filename | Stone | What the photo looks like |
|---|---|---|
| `matte-yellow-tiger-eye.jpg` | Matte Yellow Tiger Eye | Matte yellow/brown banded beads |
| `red-tiger-eye.jpg` | Red Tiger Eye | Glossy red-brown beads |
| `moss-agate.jpg` | Moss Agate | Glossy teal-green beads |
